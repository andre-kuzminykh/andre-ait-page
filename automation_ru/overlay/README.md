# Анимированная графика поверх видео — приветствие курса

Элементы трёх экранов курса (`/automation_ru/`), разложенные по озвучке
вертикального ролика 1080×1920: элемент появляется ровно тогда, когда о нём
говорят. Требование и тесты — `FR-SITE30` в [`SPEC-SITE.md`](../../SPEC-SITE.md).

Открыть: <https://andre.technology/automation_ru/overlay/>

## Постоянные правила подачи

Те же, что для лекции 1 (`FR-SITE27`), и они действуют для любой графики
поверх видео. Каждое закрыто тестом — нарушить молча не получится.

1. **Никаких прямоугольных блоков.** Круглая иконка и подпись прямо на кадре.
2. **Никаких заголовков.** «Для кого этот курс», «Чему вы научитесь» в кадр
   не идут — наверху только элементы.
3. **Только крупный текст**, у элемента одна подпись.
4. **Однотипные элементы — в ряд.**
5. **Слова не переносятся.**
6. **Графика не доходит до картин на стене** (верх рамок — y638).
7. **Текст белый.**

## Поправить слова субтитров

**Слова живут в файле [`субтитры.srt`](субтитры.srt) и только там.** Открыли
текстовым редактором, поправили, сохранили — всё.

- страница-превью читает строки оттуда;
- `собрать.sh` вжигает в кадр **тот же файл**;
- перерендеривать графику не нужно: **субтитров в слое нет**, они вжигаются
  отдельно, из этого SRT.

Копии слов внутри страницы нет намеренно — иначе правка расходилась бы с
превью. Если открыть страницу двойным кликом (`file://`), браузер соседний
файл не отдаст, и в панели появится предупреждение: запускайте через
`Запустить.command`.

37 реплик по 2–4 слова. Тайминг — из распознавания реальной дорожки, слова —
из сценария владельца; распознавалка рвала слова пополам («в AI» + «-first
компанию»), такие реплики склеены. Ни одно слово сценария не потеряно и ничего
не добавлено — это проверяется тестом.

## Готовый файл

**Кнопка «Скрипт сборки» отдаёт `собрать.sh`.** Кладёте его в эту же папку и:

```
sh собрать.sh "ваше видео.MOV"
```

Скрипт сам определит кодек, размер, поворот и звук, наложит слой графики,
вожжёт субтитры из `субтитры.srt` и проверит результат декодированием.
Заставки у этого ролика нет: обложку в ленте задаёт первый кадр.

### Слой графики: overlay_c.mp4 + overlay_a.mp4

Слой отрендерен заранее, покадрово, 30 кадров в секунду — `overlay_c.mp4` это
цвет, `overlay_a.mp4` маска прозрачности. Два файла, а не один: прозрачности в
mp4 нет, webm с альфой собирается не везде, а две видеодорожки в одном mp4 не
пережили ремукс. `alphamerge` сшивает их обратно.

Рендер: `python3 tools/render_overlay.py 59.1 <порт> <папка кадров>` — открывает
страницу с `?bg=none&still=1&cover=0` и дёргает `window.__renderAt(t)`, которая
выставляет время КАЖДОЙ анимации явно. Без этого переходы играют по часам
браузера, а снимки идут медленнее реального времени, и появления размазываются.

**Поменяли тайминги или подписи элементов — слой надо перерендерить.** Слова
субтитров к этому не относятся: их можно править свободно.

### Почему субтитры вжигаются, а не лежат в слое

Чтобы правка слова не требовала перерендера. Скрипт переводит SRT в ASS
средствами самого ffmpeg и подменяет строку стиля. Через `force_style` то же
самое не выходит: запятые внутри стиля ffmpeg считает своими разделителями, и
субтитр молча не рисуется — кадр остаётся чистым, без единой ошибки в логе.

## Параметры в адресе

| Параметр | Что делает |
|---|---|
| `?t=20` | открыть сразу на 20-й секунде |
| `?src=clip.mp4` | подхватить видео, лежащее рядом с файлом |
| `?guides=1` | показать границы: зону графики, верх картин (y638), макушку (y816) |
| `?zoneTop=70&zoneH=500` | подвинуть зону графики под конкретный кадр |
| `?scrim=0` | убрать затемнение верха кадра |
| `?subs=0` | выключить субтитры |
| `?subY=1510` | подвинуть строку субтитров по вертикали |
| `?cover=1` | включить заставку (положите рядом `cover.png`) |
| `?rec=1` | сразу режим записи (без панели) |
| `?bg=none` | прозрачный фон вместо видео — под захват в OBS/монтажке |

## Шрифты и иконки

**JetBrains Mono** — тем же шрифтом набран дек курса. Восемь подмножеств woff2
(кириллица + латиница, начертания 400/500/700/800) лежат в `fonts/`: страница
не зависит от Google Fonts и одинаково выглядит офлайн, из `file://` и с сайта.
Там же `JetBrainsMono-ExtraBold.ttf` — он нужен ffmpeg, чтобы вжечь субтитры
тем же шрифтом (woff2 libass не понимает).

**Иконки Font Awesome 6.4.0** — те же, что в деке, вклеены инлайновым SVG в
`icons.js`. Версия именно 6.4.0: в седьмой части глифов перерисованы, и графика
разошлась бы с картинкой на странице курса.
