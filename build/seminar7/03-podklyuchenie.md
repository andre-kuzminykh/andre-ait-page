# Семинар 7 · Подключение портала к Google Таблицам и n8n

Портал — интерфейс над таблицей. Каждое действие человека становится строкой журнала:
решение, оценка рекомендации, оценка ответа, исправление.

Без подключения журнал живёт только в браузере, но его можно выгрузить кнопкой «CSV».
С подключением схема такая:

```
портал ──(вебхук)──▶ n8n ──▶ Google Таблица «Журнал» ──▶ дашборд (Streamlit / DataLens)
                       └──▶ воркфлоу агента: решение человека продолжает его работу
```

В начале скрипта `index.html` есть три строки:

```js
const N8N_WEBHOOK = '';     // ⟦ВСТАВЬТЕ: Production URL вебхука журнала⟧
const DASHBOARD_URL = '';   // ⟦ВСТАВЬТЕ: ссылка на дашборд Streamlit или DataLens⟧
const CHAT_WEBHOOK = '';    // ⟦ВСТАВЬТЕ: Production URL вебхука чата⟧
```

Каждая строка независима: можно подключить только чат, только журнал или всё сразу.

---

## 1. Google Таблица «Журнал»

1. Создайте таблицу, лист назовите `journal`.
2. В первую строку впишите заголовки:
   `ts | role | agent | kind | object | action | label | id | update`
3. Значения полей:
   - `kind` — `решение`, `рекомендация` или `оценка ответа`;
   - `action` — `одобрено` / `отклонено`, `полезно` / `не полезно` или `хорошо` / `плохо`;
   - `label` — причина решения или исправленный ответ;
   - `update: true` — партнёр изменил своё решение в журнале.

## 2. Воркфлоу n8n «Журнал портала»

1. Узел **Webhook**:
   - Method `POST`;
   - Path `portal-log`;
   - Respond `Immediately`.
2. Узел **IF**: `{{$json.body.update}}` равно `true`.
   - **true** → **Google Sheets · Update Row**:
     - лист `journal`;
     - Column to Match On `id`;
     - обновить `action`, `label`.
   - **false** → **Google Sheets · Append Row**:
     - лист `journal`;
     - Mapping — каждое поле из `{{$json.body.<поле>}}`.
3. Включите воркфлоу (Active) и скопируйте **Production URL** вебхука.
4. Вставьте URL в `N8N_WEBHOOK` в `index.html`.

**CORS.** Если портал открыт как файл или с другого домена и запрос блокируется,
в узле Webhook включите **Options → Allowed Origins (CORS)** = `*`.

**Проверка.** Примите решение в портале. В n8n во вкладке **Executions** появится запуск,
в таблице — новая строка.

## 3. Связать решение человека с агентом

Для роли `decide` агент ждёт решения:
1. В воркфлоу агента перед необратимым действием поставьте узел **Wait → On Webhook Call**.
2. Вместо примеров в `CONFIG.queue` уведомления должны приходить из воркфлоу агента.
   Узел **Google Sheets · Append Row** пишет их в лист `queue`: `id, agent, text, resume_url`,
   где `resume_url` — это `{{$execution.resumeUrl}}`.
3. Воркфлоу журнала после записи решения вызывает **HTTP Request POST** на `resume_url`
   с `action` и `label`. Агент продолжает с того же места.

Для роли `recommend`: воркфлоу агента по расписанию (**Schedule Trigger**) собирает сводку
и пишет её в лист `recs`.

Для роли `chat` — готовый воркфлоу, см. следующий раздел.

> Чтобы портал читал `queue`, `recs` и ответы чата вживую, а не из примеров в `CONFIG`,
> нужна небольшая доработка скрипта: `fetch` к вебхукам n8n, которые отдают строки листов.
> Это следующий шаг после семинара — структура данных уже готова.

## 4. Живой чат с OpenAI

```
портал ──(вопрос + история)──▶ n8n: Webhook ─▶ Промт агента ─▶ OpenAI ─▶ Ответ порталу
```

**Почему через n8n, а не напрямую.** Ключ OpenAI в HTML виден любому, кто откроет файл,
и его украдут за минуты. В n8n ключ хранится в Credentials и наружу не уходит.

**Шаги:**
1. Ключ: [platform.openai.com](https://platform.openai.com) → **API keys → Create new secret key**.
   Пополните баланс, иначе API вернёт ошибку 429.
2. n8n → **Credentials → Add credential → OpenAI API** → вставьте ключ → Save.
3. **Workflows → Import from File** → `04-n8n-chat-openai.json`. В нём четыре узла:
   - **Webhook** — `POST /portal-chat`, отвечает узлом «Ответ порталу», CORS `*`;
   - **Промт агента** (Code) — системный промт с правилами и база знаний, плюс 6 последних реплик;
   - **OpenAI** (HTTP Request) — `POST https://api.openai.com/v1/chat/completions`,
     учётные данные — выбрать созданные на шаге 2;
   - **Ответ порталу** — возвращает `{"answer": "…"}`.
4. В узле **Промт агента** замените `⟦ВСТАВЬТЕ: база знаний…⟧` результатом **промта 5**.
   Там же можно сменить модель (`gpt-4o-mini` — дёшево и быстро; ⟦ВСТАВЬТЕ: другую модель из списка OpenAI, если нужно⟧).
5. **Active** → скопируйте **Production URL** (не Test URL) → вставьте в `CHAT_WEBHOOK`.

**Что шлёт портал:**
```json
{ "question": "Сколько длится диагностика?",
  "history": [{ "q": "прошлый вопрос", "a": "прошлый ответ" }],
  "role": "Методолог", "agent": "Агент-методолог", "agent_does": "Отвечает по методологии…" }
```

**Что портал понимает в ответ:** `{"answer": "…"}`, `{"output": "…"}` (так отвечает узел AI Agent),
массив с таким объектом или просто текст. Поэтому вместо HTTP Request можно поставить
узел **AI Agent** с памятью и инструментами (поиск по базе, архив кейсов) — портал менять не нужно.

**Проверка.** Задайте вопрос из базы — ответ с источником. Вопрос вне базы — «передаю эксперту».
Оценки 👍/👎 и исправления уходят в журнал, как и раньше.

**Если не работает:**

| Что видно | Причина |
|---|---|
| «Агент сейчас недоступен» сразу | воркфлоу не Active или в `CHAT_WEBHOOK` Test URL |
| ошибка в F12 про CORS | в узле Webhook: Options → Allowed Origins = `*` |
| в Executions ошибка 401 | неверный ключ в Credentials |
| в Executions ошибка 429 | закончился баланс OpenAI или лимит запросов |

## 5. Дашборд поверх таблицы

**DataLens:**
1. Подключение → **Google Sheets** → ссылка на таблицу (доступ «читатель по ссылке»).
2. Датасет по листу `journal`.
3. Графики:
   - кольцо — доля `одобрено` среди `решение`;
   - столбцы — количество строк по дням (`ts`);
   - таблица — по агентам.
4. Опубликуйте дашборд, ссылку вставьте в `DASHBOARD_URL`.

**Streamlit** (коротко):

```python
import pandas as pd, streamlit as st
url = "⟦ВСТАВЬТЕ: ссылка на лист journal в формате CSV⟧"  # Файл → Опубликовать → CSV
df = pd.read_csv(url)
st.metric("Одобрено", f"{(df.query('kind==\"решение\"').action=='одобрено').mean():.0%}")
st.bar_chart(df.groupby(df.ts.str[:10]).size())
```

Опубликуйте в Streamlit Community Cloud, ссылку вставьте в `DASHBOARD_URL`.
Кнопка «Внешний дашборд» появится в подробном дашборде портала.

- **Методолог** — 👎 с исправленным ответом: пары «вопрос → эталонный ответ».
