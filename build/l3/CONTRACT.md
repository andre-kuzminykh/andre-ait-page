## 2. Железные запреты (нарушение = слайд не принят)

1. Никаких `<style>`, `<script>`, `<svg>`, `:has()`, внешних картинок.
2. Никакого `style="..."` — КРОМЕ блока с заливкой `bg-solar`, где текст
   должен быть чёрным: `style="color:#111;-webkit-text-fill-color:#111"`.
3. Никаких `hidden md:block`, `md:hidden`, `sr-only`, `invisible` — на
   телефоне видно ровно то же, что на компьютере.
4. Никаких теней (`shadow-*`, `drop-shadow-*`).
5. Никаких `vw`/`vh`, `h-screen`, `overflow-auto`, `overflow-y-*`,
   `absolute inset-0` на весь слайд.
6. **Перед каждым `<br>` — пробел**: `Плохие <br>данные`.
7. **Каждый размер текста — парой**: `text-[10px] md:text-sm`. Одиночный
   `text-sm` без телефонного напарника запрещён (исключение — `h2` по образцу).
8. Иконка не отрывается от слова:
   `<span class="whitespace-nowrap"><i class="ph-fill ph-x"></i> Слово</span>`.
9. Имена иконок — только из `/home/user/andre-ait-page/build/l3/icons.txt`.
   Выдуманное имя рисуется пустотой. Сверяй КАЖДОЕ имя grep-ом.
10. Латиница — только из белого списка (раздел 7). «AI» запрещено, пишем «ИИ».
11. Анимация `a-orbit` вращает `transform` — её можно ставить только на
    элемент БЕЗ собственных `translate`/`rotate`-классов (обычно — пунктирное
    кольцо `absolute inset-[15%] rounded-full border-2 border-dashed`).

## 3. Канон владельца — правила из его правок (читать как закон)

Владелец выверяет колоду построчно. Всё ниже — его прямые замечания по
лекциям 3 и 4, обобщённые в правила. Нарушение любого = переделка.

**Минимализм и масштаб**

1. **«Не допускай, чтобы по масштабу были мелкие слайды».** Содержимое должно
   заполнять холст 1380×648: крупные карточки, крупные иконки, текст
   `md:text-sm…md:text-lg`. Слайд из трёх крохотных плашек посреди пустоты —
   брак («масштаб маленький», «всё мелко», «масштаб не полный»).
2. **Но и не свалка.** Не больше 5–6 крупных блоков на слайд (заголовок и
   подзаголовок — два из них). Карточек в сетке — не больше 8. Если материала
   больше — лишнее уходит в панель «Текст». Ничего не наслаивается.
3. **Никаких надписей-рубрик, которые пересказывают устройство слайда**:
   «Десять разделов пути», «Семь полей, которые заполняют до разработки»,
   «Четыре механизма меняют форму сценария», «Три оборота», «Пунктир отдан
   модели», «Круглый стол», «Чем заканчивается», «Проверьте себя» — всё это
   владелец вычёркивал. Рубрика допустима, только если без неё схема
   непонятна (например, подпись оси «до» / «после»), и тогда — 1–3 слова.
4. **Никаких порядковых цифр в элементах**: кружки «01 / 02 / 03», «1.», «шаг 2»
   — «убери цифры из элементов, вырони их». Цифры — только если это данные
   (82 → 97 %, 503, 10 секунд, 1.8).
5. **Никакого жирного в списках, плашках и пояснениях** («убери жирный
   текст», «это не надо жирным»). `font-black` — только у заголовков карточек
   (`h3`) и у ударной части полосы вывода.
6. **Воздух между блоками** — блоки не стоят вплотную; полоса вывода — внизу
   слайда, с отступом `mt-4 md:mt-8` (владелец: «чтобы вывод был внизу,
   а основная часть выровнена посередине между заголовком и выводом»).

**Строки и переносы (владелец «очень трепетно относится к переносам»)**

7. **Где можно в одну строку — в одну строку.** Подзаголовок слайда — строго
   одна строка на компьютере (≤ 62 знаков). Плашка-тег — одна строка
   (1–3 слова). Заголовок карточки — одна строка, если это 1–2 слова.
   Если не влезает — сокращаем текст, а не мельчим кегль.
8. **Где две строки — перенос по смыслу, а не где придётся.** Второе
   предложение, пояснение после тире, вторая половина противопоставления
   («…, а не …», «— вместо …», «а оценка решает, стало ли лучше») уходят на
   новую строку явным ` <br>`. Висячее одно слово на второй строке — брак.
9. **Максимум три строки текста в любом блоке.** Длиннее — в панель «Текст».
10. **Полоса вывода: две строки максимум**, обычная часть — первой строкой,
    ударная `font-black` — второй через ` <br>`. Одна строка — ещё лучше.
11. Длинное слово в узкой колонке: мягкий перенос `Инстру&shy;менты`. Но лучше
    подобрать короче слово или дать колонке ширину, чем рвать.

**Выравнивание**

12. **Всё по центру**: иконка и слово в карточке центрированы по горизонтали
    и вертикали («по середине выровни иконки и слова»); текст в карточках
    ряда — `text-center`, содержимое — `items-center justify-center`.
13. **Ряд карточек — одной высоты и одной ширины** (`grid` + `items-stretch`,
    у карточек `h-full`), подписи одного кегля. Левый и правый блоки слайда —
    на одном уровне по верху и низу («выронить слева и справа блоки на одном
    уровне»); две соседние карточки разной длины — выравнивать по длине.
14. **Иконка прижата к своему слову** (`gap-1…gap-2`), не висит в углу.
15. **Однородность**: если в одной из параллельных карточек есть галочки,
    стрелки или иконки-маркеры — они есть во всех («галочки ещё на 1 и 2 блоке»).
16. **Круг — это круг, а не яйцо**: кольцевые схемы только через
    `relative w-full aspect-square` внутри обёртки, задающей диаметр
    (раздел 5). Узлы по окружности — одинаковой ширины, стрелки между ними —
    по касательной.

**Слова**

17. **Меньше англицизмов — только там, где реально нужно** (раздел 7).
    Предпочтения владельца: «логи» (а не «журналы»), «интеграция» (а не
    «связи систем»), «бизнес-логика» (а не «деловая логика»), «трейс».
18. Текст на слайде — выжимка из текста для озвучки: ключевые понятия,
    пары, цифры и пример. Ничего из списка «обязательное содержание» не терять,
    но и не переписывать абзацы на слайд.

```html
<div class="bg-solar/20 border-l-4 border-solar p-2.5 md:p-4 rounded-r-xl md:rounded-r-2xl w-full max-w-3xl mx-auto text-center mt-4 md:mt-8">

```
**Шкала/полоса-градиент** (уровни, режимы, риск): ряд одинаковых сегментов
`flex-1` с нарастающей заливкой `bg-solar/10 → bg-solar/25 → bg-solar/45 → bg-solar`.
**Тёмная панель-сравнение «было / стало»**: две колонки, левая серая, правая
тёмная, между ними стрелка.

Сетки: `grid grid-cols-2 md:grid-cols-4 gap-2 md:gap-4`. На телефоне ряд из
четырёх складывается в 2×2 — норма. Ряд из трёх на телефоне —
`grid-cols-1 md:grid-cols-3` (стопка) или `grid-cols-3` (подписи короткие).
Ряд из пяти — `grid-cols-2 md:grid-cols-5`, пятой карточке на телефоне
`col-span-2 md:col-span-1`.

**Анимация** (только эти классы): `a-in` + `a-in-2`…`a-in-6` (появление по
очереди), `a-pulse` (дыхание акцента), `a-flow` / `a-flow-y` (бегущий пунктир),
`a-orbit` (вращение пунктирного кольца), `a-step` + `a-step-2`/`a-step-3`
(подсветка узлов цикла по очереди). Анимации по возможности — живая схема
лучше мёртвой: кольца крутятся, линии бегут, узлы цикла загораются.

## 6. Телефон (376×844) — чтобы не мельчало и не рвалось

* Пол кегля на телефоне — 10px эффективных. Базовые телефонные размеры:
  подписи `text-[9px]`…`text-[11px]` (slide-polish поднимает их до 11.5–12.5px).
* `annotate()` сам складывает в стопку `flex flex-row` БЕЗ `md:flex-row`, если в
  нём ≥ 3 детей. Если ряд должен остаться рядом и на телефоне — добавь класс
  `js-keep`.
* Сужения «только для компьютера» пиши с `md:` (`md:w-[38%]`), на телефоне —
  `w-full` или `flex-1`: иначе на телефоне вылезает.
* Карточка «иконка + текст» в стопке на телефоне сама ложится строкой — это
  делает JS, отдельно размечать не нужно.
* Ничего не прячем. Телефон показывает ровно тот же текст.
