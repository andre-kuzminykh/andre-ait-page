# AGENTS.md — правила работы с репозиторием andre-ait-page

Инструкции для ИИ-агентов и людей, работающих с этим репозиторием.

## Что это

Статический сайт **andre.technology** (GitHub Pages, файл `CNAME`).
Прод = ветка **`main`**: всё, что попадает в `main`, сразу уходит на сайт.

- `index.html` — весь главный сайт одним файлом: инлайновые CSS и vanilla-JS,
  без сборки, без зависимостей. Слайд-дек с фикс-вьюпортом
  (`html,body{overflow:hidden}`), экраны переключаются JS-роутером (`ORDER`/`SCREENS`).
- `automation/` — страницы курса по автоматизации:
  - `index.html` (+ статические копии `roles/`, `skills/`) — SPA-визард из 3 шагов;
  - `main/index.html` — дорожная карта курса;
  - `1/` … `8/` — лекции-презентации (Tailwind, отдельный «портальный» дизайн —
    их стиль НЕ приводится к главной странице); контент лекций 3–8 перенесён из
    репозитория `aisala` (`ai-agents-corp`), видео-головы лекций 6–8 лежат в
    репозитории `automation` (ветка `ai-agents-corp-videos`, raw по SHA);
- `backup/` — ручные бэкапы состояний (не трогать);
- `tests/` — тесты без зависимостей (см. ниже);
- `SPEC-SITE.md` — **спека: как всё должно работать**. Источник правды.

## Правила работы

1. **Никогда не коммитить в `main` напрямую.** Работа — в фичевой ветке,
   в `main` — через pull request.
2. **Прочитай `SPEC-SITE.md` до правок.** Каждое требование имеет ID
   (`FR-SITE-N`) и привязанные тесты. Не ломай существующие FR.
3. **Новое требование = новый FR в `SPEC-SITE.md` + тест** в `tests/`.
   Формат: Story → Требование → Тесты (см. существующие секции).
4. **Перед пушем прогони тесты** (без зависимостей, нужен только python3):
   ```
   python3 tests/test_site.py
   python3 tests/test_automation.py
   python3 tests/test_lectures.py
   ```
5. **Вёрстку проверяй в реальном браузере** (Playwright/Chromium): десктоп
   1440×900 и 1024×768, мобилка 390×844; для automation-страниц — обе темы
   (тёмная/светлая). Смотри переполнения (`scrollWidth > clientWidth`),
   перекрытия шапки и ошибки в консоли.
6. **Комментарии в коде объясняют «почему»** (со ссылкой на FR-SITE-N или
   жалобу пользователя), а не «что». Стиль — как в существующем коде.

## Конвенции вёрстки

- Mobile-first; десктоп-брейкпоинт — `@media (min-width:1024px)`.
- Шрифт всего сайта и automation-визарда — **JetBrains Mono** (Google Fonts).
- Цвета бренда: фиолетовый `#8854F3`, оранжевый `#F97316`, фон `#050505`.
- Большие экраны масштабируются `body{zoom}` (1600/1900/2300px) — помни, что
  zoom искажает viewport-единицы (`100dvh` рендерится больше экрана) и
  координаты `getBoundingClientRect`.
- Кнопки — `.btn-white` (белая пилюля, градиент-шиммер на hover); высота
  десктопных элементов шапки — `2.85rem`.

`checkpoint/*`-теги локально, если доступны).
