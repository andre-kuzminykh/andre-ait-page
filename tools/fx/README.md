# Сценарии подсветки слайдов (`tools/fx/lecture1-slideNN.json`)

Сценарий описывает, **какое слово речи** зажигает **какой элемент слайда** и
**каким эффектом**. Времена берутся не «на глаз», а из распознанной речи:
`build/timings/lecture1-slideNN.json` (слова с таймингом, whisper).

Рендер: `python3 tools/animate_slide.py --slide N` →
`build/lecture1-slideNN.mp4` (кадры 1920×1080 + кружок говорящей головы).

## Откуда брать текст элемента

Из инвентаря `build/fx-inventory/lecture1-slideNN.json` — он снят с живой
страницы и содержит ровно то, что ищет рендер:

```
items[].text   строка ДОСЛОВНО (сравнение точное, пробелы уже нормализованы)
items[].kids   сколько потомков (рендер берёт элемент с наименьшим числом)
items[].rect   [x, y, ширина, высота] при 1920×1080
items[].dubl   true — такой же текст встречается ещё где-то, будь осторожнее
items[].up1/2  что находится на уровень и два выше (это и даёт поле `up`)
words[]        слова речи: {w: «слово», s: начало, e: конец}
speech         вся речь слайда одной строкой
```

Внимание: в текстах лекции встречается **неразрывный дефис** `‑` (U+2011) —
«ИИ‑агенты». Копируйте строку из инвентаря как есть, не набирайте руками.

## Поля реплики

| поле | что делает |
|---|---|
| `word` | слово речи, на котором зажигается эффект. Точное слово — любой длины, по корню — от 5 букв (падежи ок). Повторы разруливаются полем `at` — берётся ближайшее вхождение |
| `at` | секунда-ориентир (и запасное время, если слово не нашлось) |
| `text` | дословный текст элемента из инвентаря |
| `up` | подняться на N предков (0 — сам элемент) |
| `fx` | эффект, см. ниже |
| `dur` | сколько горит подсветка, 1.2–3.0. Автоматически ужимается до следующей реплики |
| `grow` | насколько подрастает элемент, по умолчанию 0.06. Для слова ВНУТРИ строки — 0.015 |
| `tight` | true — обводка вплотную (для слова внутри строки) |
| `burst` | эмодзи, который вылетает **из-за** элемента |
| `n` | сколько эмодзи, 8–14 |
| `burst_dur` | длительность полёта, по умолчанию 1.8 с |

## Эффекты

- `pop` — рывок с фиолетовым ореолом. Заголовок слайда, один раз в начале.
- `glow-violet` / `glow-solar` — обводка + свечение (фиолетовое / оранжевое).
  Рабочая лошадка для карточек и плашек. Цвета чередуем.
- `frame` — только оранжевая рамка, без свечения и без роста. Для широких
  плашек-выводов, которые нельзя дёргать.
- `underline` — подчёркивание прорисовывается слева направо. Для строки-тезиса.
- `rise` — карточка всплывает и подсвечивается снизу. Для рядов одинаковых
  плиток: движение читается лучше обводки.
- `none` — элемент не трогаем, нужен только как точка вылета эмодзи.

## Правила хорошего сценария

1. **4–7 реплик на слайд** — примерно одна на 5 секунд речи. Больше — рябит.
2. **Первая реплика — заголовок**, `fx: "pop"`, на первом же слове темы.
3. **Слово и элемент связаны по смыслу**: голос говорит «восприятие» —
   загорается карточка «Восприятие». Подсветка «просто так» запрещена.
4. **Эмодзи — только там, где он усиливает мысль** (👁 к восприятию, 🧠 к
   мышлению, 💰 к деньгам, 🚀 к росту). Не больше 2–3 всплесков на слайд.
5. **Слово внутри строки** (не отдельная карточка) — `grow: 0.015` +
   `tight: true`, иначе оно наезжает на соседние слова.
6. **Соседние по времени реплики — разными цветами**, чтобы не сливались.
7. **Порядок реплик в файле — по времени речи.**
8. **Не подсвечивайте элемент, у которого в классах уже есть `scale-…`**
   (например `lg:scale-105`): эффект переписывает `transform` целиком, и в
   момент вспышки карточка скачком «сдувается» к масштабу 1. Подсветите
   вложенный список или соседний уровень — смысл тот же, рывка нет.

## Скелет

```json
{
  "_": "О чём слайд и почему выбраны эти акценты",
  "slide": 4,
  "clip_seconds": 30.0,
  "cues": [
    {"word": "агент", "at": 1.0, "text": "Кто такие ИИ‑агенты?", "up": 0,
     "fx": "pop", "dur": 1.2},
    {"word": "восприятие", "at": 8.0, "up": 0, "fx": "glow-violet", "dur": 3.0,
     "text": "Восприятие Видит контекст, почту, базы данных и системы",
     "burst": "👁", "n": 10}
  ]
}
```

Проверка перед рендером: `python3 tools/fx_check.py` — сверяет каждый `text`
с инвентарём, каждое `word` с речью и показывает итоговый тайминг.
