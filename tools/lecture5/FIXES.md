# Правки лекции 5 по списку владельца

Нумерация владельца = **индекс слайда + 1** (как показывает панель «Текст»:
«СЛАЙД 21 / 47» — это `id="slide-20"`). Сверено по каждому пункту: все
процитированные строки нашлись на слайде с этим индексом.

Статусы: `[ ]` не сделано · `[x]` сделано и проверено · `[?]` трактовка,
нужна проверка владельцем.

## Приёмка круга

После правок обязательно, из корня репозитория:

```bash
python3 tools/lecture5/lint.py                 # разметка слайдов
python3 tools/lecture5/assemble.py             # пересборка колоды
python3 tools/build_lecture_css.py 5           # CSS (новые классы!)
python3 tools/measure_floor.py 5               # общий кегль → build/l5/floor.json
python3 tools/lecture5/assemble.py             # пересобрать с новым __FLOOR
python3 tools/lecture_check.py vse 5           # все сканеры
python3 tools/lecture_check.py kadry 5 <метка> # кадры
python3 tools/lecture_check.py sverka <до> <после>
python3 -m pytest -q
```

Норма: `kegl` ≥ 10px, `kraya` 0, `parnost` 0, `perenos` 0, `ikonki` 0,
`transform` 0, `perehod` 0. Кадры изменившихся слайдов просмотреть глазами
на обеих формах; кадры НЕтронутых слайдов при сверке должны дать 0 отличий.
