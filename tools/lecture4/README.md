# Как собиралась лекция 4

Колода `automation/4/index.html` не писалась руками целиком: 43 слайда и
столько же текстов панели «Текст» собраны генератором из трёх источников.
Здесь лежит вся оснастка, чтобы лекцию можно было пересобрать и чтобы
лекция 5 делалась тем же путём.

| Файл | Что это |
|---|---|
| `source-1.md`, `source-2.md`, `source-3.md` | исходный текст лекции от владельца, десять разделов по четыре темы |
| `plan.py` | план колоды: заголовок, подзаголовок, схема инфографики и обязательное содержание каждого слайда; генерирует задания `build/l4/specs/slide-NN.md` |
| `CONTRACT.md` | контракт вёрстки слайда: словарь классов, запреты, плотность |
| `OFFLOAD.md` | разгрузка слайда до нормы кегля на телефоне (П5) с проверенным рецептом |
| `lint.py` | механическая проверка разметки слайда до браузера |
| `lint_notes.py` | проверка текста панели |
| `kegl_one.py` | быстрый замер кегля ОДНОГО слайда на телефоне |
| `assemble.py` | сборка `automation/4/index.html` из каркаса лекции 3 и готовых слайдов |
| `quiz.json` | вопросы финального теста, по одному на раздел |

Порядок сборки:

```bash
python3 tools/lecture4/plan.py                  # задания на слайды
#   ... вёрстка слайдов в build/l4/out/slide-NN.html
python3 tools/lecture4/lint.py                  # разметка чистая
python3 tools/lecture4/assemble.py              # automation/4/index.html
python3 tools/build_lecture_css.py 4            # assets/lecture-4.css
python3 tools/measure_floor.py 4 --write        # общий кегль заголовков
python3 tools/lecture_check.py vse 4            # все сканеры приёмки
```

Пути внутри скриптов рассчитаны на рабочий каталог `build/l4/` (он в
`.gitignore`): там лежат задания, заготовки слайдов и тексты панели. Готовый
результат — сама лекция и собранный CSS — в репозитории.
