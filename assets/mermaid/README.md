# mermaid — своя копия, без чужого CDN

Схемы на странице практики (`automation/2/practice/`) рисует mermaid. Раньше
библиотека тянулась с `cdn.jsdelivr.net`: в закрытой корпоративной сети, при
сбое CDN или просто на медленном ответе страница оставалась без схем. Теперь
сборка лежит здесь и отдаётся с того же домена, что и сама страница.

## Что лежит

    assets/mermaid/11.17.2/
      mermaid.esm.min.js              точка входа (30 КБ)
      chunks/mermaid.esm.min/*.js     103 куска, 3,3 МБ
      LICENSE                         MIT, как у mermaid

Версия — в пути. Обновление кладётся **соседней папкой** (`11.18.0/` и т. д.),
старая остаётся на месте: ссылки не ломаются и кэш браузера не путается.

Сборка модульная: страница подтягивает точку входа, та — только нужный тип
схемы. На flowchart уходит около 800 КБ, на sequenceDiagram — ещё 115 КБ.
Всю библиотеку разом никто не качает.

## Откуда взято и как переименовано

    npm pack mermaid@11.17.2
    tar xzf mermaid-11.17.2.tgz
    # берём только минифицированную модульную сборку, без .map и .d.ts
    package/dist/mermaid.esm.min.mjs        → mermaid.esm.min.js
    package/dist/chunks/mermaid.esm.min/*.mjs → chunks/mermaid.esm.min/*.js
    package/LICENSE                        → LICENSE

Расширение сменено с `.mjs` на `.js` намеренно: GitHub Pages отдаёт статику по
своей таблице типов, а модуль, пришедший не как `text/javascript`, браузер не
исполняет вовсе. На `.js` этот тип отдают все. Вместе с файлами переписаны и
ссылки внутри них — только относительные пути импортов вида `"./имя.mjs"`
(923 штуки). Строки, которые путями не являются (например имя пакета
`dompurify/dist/purify.es.mjs`), не тронуты. Больше в коде библиотеки не
изменено ничего.

Целостность дерева стережёт `tests/test_course_entry.py`:
`test_practice2_mermaid_is_vendored_and_complete` проверяет, что импорт ведёт
на свой домен, что файл на месте, что рядом лежит лицензия и что **все куски,
на которые ссылается точка входа, скопированы** — недокопированный кусок
всплыл бы не на загрузке страницы, а на первой схеме такого типа, то есть у
зрителя.
