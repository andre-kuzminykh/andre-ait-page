Сценарий описывается простыми шагами

Формат

Given — состояние пользователя
When — что он делает
Then — что выполняет система

Пример

Given: Пользователь в главном меню
When: Нажимает «Пройти диагностику»
Then: Система показывает первый вопрос из JSON
Связывает продуктовую логику, реализацию и тестирование
