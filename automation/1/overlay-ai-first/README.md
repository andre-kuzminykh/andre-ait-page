# Анимированная графика поверх видео — эволюция ИИ и AI-First (слайды 9–12)

Элементы слайдов 9–12 лекции 1 (`/automation/1/`), разложенные по озвучке
вертикального ролика 1080×1920: элемент появляется ровно тогда, когда о нём
говорят. Третий ролик серии — после слайдов 1–3 (`../overlay/`) и слайдов 4–8
(`../overlay-agents/`).

Открыть: <https://andre.technology/automation/1/overlay-ai-first/>

## Постоянные правила подачи

Те же семь, что у прошлых роликов, и они действуют для любой графики поверх
видео. Каждое закрыто тестом в `tests/test_ai_first_overlay.py`.

1. **Никаких прямоугольных блоков.** Круг — единственная допустимая оправа.
2. **Никаких заголовков.** Заголовки слайдов в кадр не идут.
3. **Только крупный текст**, минимум 24px при ширине кадра 1080; у элемента
   одна подпись.
4. **Однотипные элементы — в ряд.**
5. **Слова не переносятся.**
6. **Графика не доходит до картин на стене** (верх рамок — y638): зона 250…630.
7. **Текст белый.**

Сверху кадра — фирменная шапка: лого AIT слева и «АКАДЕМИЯ ДАТАИСТА» по
центру, геометрия 1:1 с хромом рилсов Академии.

## Как устроено выделение (правило на всю раскладку)

Элементы сцены **одного размера и на одной высоте**. Иерархию несёт не
диаметр, а выделение: пока об элементе говорят, он чуть подрастает (×1.12) и
берётся во **внешнее кольцо**, потом плавно возвращается на место. Соседи при
этом **не гаснут** — прозрачность не меняется ни у кого. Цвета чередуются
фиолетовый / оранжевый.

Времена сведены с дорожкой: границы взяты из распознавания, каждый элемент
привязан к своей реплике. Стоят прямо в разметке: `data-in` — когда элемент
выходит, `data-cur` — окна «о нём говорят прямо сейчас» (парами, элемент
можно подсветить дважды за сцену). Сдвинулась озвучка — правятся только эти
числа.

Два пустых участка намеренные: 88.4–100.8 («Каждый следующий уровень…» —
обобщение уже показанного) и 128.9–132.6 (связка перед слайдом 12). Кадр в них
отдан говорящему.

### Почему уровни — столбики, а не ряд кружков

Пять подписей в один ряд не влезают: на подпись остаётся 18.7px при минимуме
24px. Столбики решают сразу две задачи — подписи получают всю ширину колонки
(25px), а высота столбика сама показывает рост уровня, который в тексте и
описан («каждый следующий уровень включает возможности предыдущего»).

Прямоугольника при этом нет: вершина скруглена по половине ширины — столбик с
куполом, иконка ложится ровно в купол, — а низ уходит в прозрачность, поэтому
нижнего края не видно и линии-базы под диаграммой нет.

### Анимации

- **линия таймлайна прочерчивается** слева направо (`drawLine`, 1.1 c) — эпохи
  выходят на уже проведённую линию;
- **столбик вырастает снизу** (`scaleY` .04 → 1, 0.78 c), иконка и подпись при
  этом не тянутся: заливка отдельным слоем;
- **выделение** — кольцо + ×1.12 с плавным возвратом, соседи не гаснут;
- **сияние дышит** (`glowPulse`), **звёздочки мерцают** (`starTwinkle`).

### Шапка не пропадает никогда

Лого AIT и «АКАДЕМИЯ ДАТАИСТА» видны весь ролик и прячутся только на обложке.
Слой конечен (167.0 c), а дубль может оказаться длиннее — тогда после конца
слоя шли бы голые кадры без шапки. Поэтому последние две секунды в слое
остаётся ОДНА шапка, а `собрать.sh` держит этот кадр до конца ролика
(`tpad=stop=-1:stop_mode=clone`). Сколько бы ни длился ваш дубль, шапка
останется в кадре.

## Поправить слова субтитров

**Слова живут в файле [`субтитры.srt`](субтитры.srt) и только там.** Открыли
текстовым редактором, поправили, сохранили — всё.

- страница-превью читает строки оттуда;
- `собрать.sh` вжигает в кадр **тот же файл**;
- перерендеривать графику не нужно: **субтитров в слое нет**.

96 реплик по 2–4 слова, 363 слова. Тайминг — из распознавания реальной
дорожки, слова — из сценария владельца: распознавалка теряла ё («жёстким»,
«Четвёртый») и слышала «сформулировался» вместо «сформировался». Ни одно слово
сценария не потеряно и ничего не добавлено — это проверяется тестом.
Последняя реплика единственная в пять слов: иначе «ими.» мигало бы отдельной
строкой на четверть секунды.

Если открыть страницу двойным кликом (`file://`), браузер соседний файл не
отдаст, и в панели появится предупреждение: запускайте через
`Запустить.command`.

## Готовый файл

**Кнопка «Скрипт сборки» отдаёт `собрать.sh`.** Кладёте его в эту же папку и:

```
sh собрать.sh "ваше видео.MOV"
```

Скрипт сам определит кодек, размер, поворот и звук, наложит слой графики,
вожжёт субтитры из `субтитры.srt`, приклеит спереди обложку на 0.2 секунды
(она же превью в ленте) и проверит результат декодированием.

**Обложка необязательна.** Лежит рядом `cover.png` — берётся она; нет файла —
скрипт возьмёт первый кадр вашего дубля и скажет об этом в логе. Хотите свою
картинку — просто положите `cover.png` в папку.

Звук идёт **копией** — без пережима, бит-в-бит. Частота кадров держится явным
`-r`: после склейки с обложкой ffmpeg молча писал 25 к/с и выбрасывал каждый
шестой кадр 30-кадрового ролика.

### Слой графики: overlay_c.mp4 + overlay_a.mp4

Слой отрендерен заранее, покадрово, 30 кадров в секунду — `overlay_c.mp4` это
цвет, `overlay_a.mp4` маска прозрачности. Два файла, а не один: прозрачности в
mp4 нет, webm с альфой собирается не везде, а две видеодорожки в одном mp4 не
пережили ремукс. `alphamerge` сшивает их обратно.

Рендер: `python3 tools/render_overlay.py 167.0 <порт> <папка кадров> "&subs=0"`.

**Поменяли тайминги или подписи элементов — слой надо перерендерить.** Слова
субтитров к этому не относятся.

## Если ffmpeg урезанный (conda) — сборка всё равно пройдёт

В терминале с активной conda команда `ffmpeg` часто означает её сборку без
libass — она не умеет вжигать текст. Скрипт это определяет сам:

- нашёлся полный ffmpeg — субтитры вжигаются из `субтитры.srt`;
- полного нет — субтитры берутся из готового слоя `subs_c.mp4`/`subs_a.mp4`.

У готового слоя один предел: он отрендерен из конкретного текста. Если
`субтитры.srt` правился, сборка без libass честно остановится (сверяется хэш
в `субтитры.sha`), а не соберёт ролик со старыми словами.

## Шрифты и иконки

**Montserrat** — тем же шрифтом набран дек лекции. Подмножества woff2 лежат в
`fonts/`. Там же `Montserrat-Black.ttf` — он нужен ffmpeg, чтобы вжечь
субтитры тем же шрифтом (woff2 libass не понимает). Он собран из двух
подмножеств woff2 в один файл: libass берёт только ttf и только один файл, а
кириллица с латиницей у Montserrat лежат раздельно.

**Иконки Phosphor** — те же глифы, что стоят на слайдах дека, вклеены
инлайновым SVG.

## Параметры в адресе

| Параметр | Что делает |
|---|---|
| `?t=95` | открыть сразу на 95-й секунде |
| `?src=clip.mp4` | подхватить видео, лежащее рядом с файлом |
| `?guides=1` | показать границы: зону графики, верх картин (y638), макушку (y816) |
| `?zoneTop=250&zoneH=380` | подвинуть зону графики под конкретный кадр |
| `?scrim=0` | убрать затемнение верха кадра |
| `?subs=0` | выключить субтитры |
| `?only=subs` | оставить в кадре ТОЛЬКО субтитры (рендер запасного слоя) |
| `?subY=1510` | подвинуть строку субтитров по вертикали |
| `?cover=0` | убрать заставку (по умолчанию 0.2 c) |
| `?rec=1` | сразу режим записи (без панели) |
| `?bg=none` | прозрачный фон вместо видео — под захват |
