# Анимированная графика поверх видео — три трансформации бизнеса (слайды 17–21)

Элементы слайдов 17–21 лекции 1 (`/automation/1/`) — «Эволюция операционных
моделей», «Agile-трансформация», «Цифровая трансформация», «ИИ-трансформация»,
«Уровни зрелости бизнес-модели» — разложенные по озвучке вертикального ролика
1080×1920: элемент появляется ровно тогда, когда о нём говорят. Пятый ролик
серии.

Открыть: <https://andre.technology/automation/1/overlay-transform/>

## Постоянные правила подачи

Те же семь, что у прошлых роликов.

1. **Никаких прямоугольных блоков.** Круг — единственная допустимая оправа.
2. **Никаких заголовков.** Заголовки слайдов в кадр не идут.
3. **Только крупный текст**, минимум 24px при ширине кадра 1080.
4. **Однотипные элементы — в ряд** (или сеткой, если в ряд не влезают).
5. **Слова не переносятся.**
6. **Графика не доходит до картин на стене** (верх рамок — y638): зона 238…630.
7. **Текст белый.**

Выделение: пока об элементе говорят, он подрастает (×1.12) и берётся во
внешнее кольцо, потом плавно возвращается. Соседи **не гаснут**. Цвета
чередуются фиолетовый / оранжевый. Шапка AIT + «АКАДЕМИЯ ДАТАИСТА» — весь
ролик, кроме обложки.

Правки владельца по этому ролику, которые теперь тоже правила:

- **в кадре «ИИ», а не «AI»** — латиницей остались только названия уровней
  зрелости (AI-Driven / AI-First / AI-Native), так они звучат и на слайде;
- **однотипное подписывается по отдельности и выходит по очереди** — не
  «Задачи» одной подписью на три круга, а «Задача 1» · «Задача 2» · «Задача 3»;
- **связи живые** — там, где нарисована сетка, по ней бежит ток;
- **два элемента в кадре стоят широко** — каждый над своей картиной (центры
  235 и 820 по кадру), середина свободна: там голова;
- **каждый круг подсвечивается ровно один раз** и в кадре в этот момент
  горит только он: два кольца разом владелец забраковал сразу;
- **кольцо — не украшение:** там, где смысл несут связи (матрица) или
  порядок появления (задачи), кружки не подсвечиваются вовсе;
- **если под кругом ничего не подписано у соседа — не подписываем и здесь**
  (так у пары Data-driven / Intelligence-driven), вместо подписи работают
  цветной градиент за кругом и вылетающие значки.

**Вылетающие значки — это Phosphor, а не эмодзи.** Эмодзи рисуются
системным шрифтом, которого на чужой машине может не оказаться, и вместо
мозга вышел бы пустой квадрат. Значки те же, что в кругах, белые, с
цветным ореолом: на оранжевом градиенте оранжевая цифра пропадала.

Времена стоят прямо в разметке: `data-in` — когда элемент выходит,
`data-out` — когда уходит, `data-cur` — окна «о нём говорят прямо сейчас».
Сдвинулась озвучка — правятся только эти числа.

**Каждый элемент сверен с дорожкой:** все 83 появления элементов и 37 окон подсветки
попадают внутрь реплик, иначе графика шла бы сама по себе, а речь сама по
себе. Проверка печатает для каждого элемента, что звучит в его момент.

## Собрать ролик, потом нарезать на пять

```
sh собрать.sh "ваше видео.MOV"                            # один ролик целиком
sh нарезать.sh "ваше видео-готовый.mp4" 35.5 72 107 142   # пять частей
```

Числа реза — по границам блоков: 35.5 (конец обзора трёх трансформаций),
72 (конец Agile), 107 (конец цифровой), 142 (конец ИИ-трансформации).

**Второй раз собирать `…-готовый.mp4` нельзя**: субтитры в нём уже вжжены, и
новый заход положил бы поверх них вторую строку. Скрипт видит такое имя и
останавливается.

**Обложки уже готовы:** `cover.png` — на весь ролик, `cover1.jpg`…`cover5.jpg` —
по одной на часть, с подписью «Часть N» под тайтлом. Скрипт нарезки видит
пронумерованные обложки и не рисует подпись поверх второй раз.

## Субтитры

**Ни одна реплика не переносится на две строки.** Каждая измерена по метрикам
шрифта (`tools/ttf_width.py`) и, если не влезала в полосу 940px, разрезана по
словам. 141 реплика, 373 слова, самая широкая строка 883px.

**Времена из распознавания, слова из сценария.** Распознавалка ставила водяной
знак TurboScribe, рвала слова по дефису на две реплики («и AI» + «-трансформацию»),
теряла ё («жесткой», «перевел», «все еще») и развалила фразу «Эта гибкость
стала фундаментом» в «Это гибко и стало». Всё это поправлено; кроме того,
обрывки по два слова слиты в читаемые строки — распознавалка резала речь
кусками по 0.2 c.

**Кегль вжжённых субтитров = кегль на странице.** libass (как и VSFilter)
понимает `Fontsize` не как размер em, а как высоту строки `winAscent+winDescent`
из таблицы OS/2. У Montserrat Black это 1.562em, поэтому «Fontsize 53»
рисовался в кадре как 34px — в полтора раза мельче, чем показывает превью и
чем лежит в запасном слое. Скрипт умножает кегль на 1.562, и обе дороги
сборки дают один и тот же кадр.

Слова живут в `субтитры.srt` и только там: страница-превью читает тот же файл,
который вжигает `собрать.sh`. Перерендеривать графику ради правки слова не
нужно — субтитров в слое графики нет. Если ваш ffmpeg без libass, текст
берётся из готового слоя `subs_c.mp4`/`subs_a.mp4`, и правку слов скрипт
заметит по хэшу `субтитры.sha`: честно остановится, а не соберёт со старым
текстом.

## Слой графики

`overlay_c.mp4` — цвет, `overlay_a.mp4` — маска прозрачности (в mp4 нет альфы,
`alphamerge` сшивает их обратно). Слой 181.0 c при дорожке 179.7: в хвосте
остаётся одна шапка, и `собрать.sh` держит этот кадр до конца дубля
(`tpad=stop=-1:stop_mode=clone`) — шапка не пропадает, даже если ваш дубль
длиннее.

Пересобрать страницу из исходников: `python3 tools/build_transform.py`.
Перерендерить слой: `python3 tools/render_overlay.py 181.0 <порт> <папка> "&subs=0"`.

## Параметры в адресе

| Параметр | Что делает |
|---|---|
| `?t=95` | открыть сразу на 95-й секунде |
| `?src=clip.mp4` | подхватить видео, лежащее рядом с файлом |
| `?guides=1` | показать границы зоны и верх картин |
| `?scrim=0` | убрать затемнение верха кадра |
| `?subs=0` | выключить субтитры |
| `?only=subs` | оставить в кадре только субтитры (рендер запасного слоя) |
| `?cover=0` | убрать заставку |
| `?rec=1` | режим записи без панели |
| `?bg=none` | прозрачный фон — под захват |
