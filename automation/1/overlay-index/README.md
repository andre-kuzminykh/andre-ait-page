# Анимированная графика поверх видео — ИИ-индекс зрелости (слайды 22–30)

Элементы слайдов 22–30 лекции 1 (`/automation/1/`) — «Зачем компании нужен
ИИ-индекс зрелости», семь измерений индекса и «Что делать с ИИ-индексом» —
разложенные по озвучке вертикального ролика 1080×1920: элемент появляется
ровно тогда, когда о нём говорят. Шестой ролик серии.

Открыть: <https://andre.technology/automation/1/overlay-index/>

## Постоянные правила подачи

Те же семь, что у прошлых роликов.

1. **Никаких прямоугольных блоков.** Круг — единственная допустимая оправа.
2. **Никаких заголовков слайдов.** В кадр они не идут.
3. **Только крупный текст**, минимум 24px при ширине кадра 1080.
4. **Однотипные элементы — в ряд** (или сеткой, если в ряд не влезают).
5. **Слова не переносятся.**
6. **Графика не доходит до картин на стене** (верх рамок — y638): зона 238…630.
7. **Текст белый.**

Плюс правила, которые накопились за прошлые ролики и действуют здесь:

- в кадре **«ИИ», а не «AI»** — латиницей осталась только «AI-first модель»,
  это название уровня;
- **одно кольцо на элемент**, и в кадре одновременно горит только один;
- **кольцо — не украшение:** там, где смысл несут связи или порядок
  появления, подсветки нет вовсе;
- **соседи не гаснут** — выделение работает подростом и цветом, а не
  затуханием остальных;
- цвета чередуются **фиолетовый / оранжевый**; шапка AIT + «АКАДЕМИЯ
  ДАТАИСТА» — весь ролик, кроме обложки.

**Главное отличие этого ролика.** Владелец: «давай только заголовки — Данные
/ Модели и т.д., без иконок, а оранжевым / фиолетовым сзади свечением и
эмодзи слева справа». У семи блоков круга с иконкой нет совсем: в кадре само
слово, за ним цветное сияние, а из-за краёв слова разлетаются значки — свои
у каждого блока. Подсказки под заголовком тоже без кружков: просто слова,
и подсвечиваются они цветом с лёгким подростом.

Ещё три правила, которые владелец задал по этому кадру:

- **значки летят 3–4 секунды**, а не весь блок: один проход анимации, с
  задержками последний гаснет на 3.7-й секунде после появления слова;
- **сияние по размеру слова.** Одно облако на всех выглядело пятном втрое
  больше короткого «Данные» — ширину теперь считает сборщик по ширине
  заголовка (520…900px);
- **больше четырёх подсказок — два ряда.** В строку столько не помещается.

## Две вещи, которые посчитаны, а не прикинуты

**Кегль заголовка 54.** На 64 «Исследования и разработки» занимают 1029px и
в кадр шириной 988 не помещаются — посчитано по метрикам шрифта
(`tools/ttf_width.py`), а не подобрано на глаз.

**Куда лететь значкам, решает сборщик.** Запас сбоку зависит от длины слова:
у «Данных» это 363px, у «Исследований и разработок» — 50px, и там значки
улетали за край кадра. Теперь запас меряется, и если вбок тесно, веер уходит
ВВЕРХ, где место есть всегда.

**Стрелка дорожной карты нарисована по замеру.** Круги стоят на 197 / 540 /
883 по кадру, а svg связи начинается с 46 — концы линии, посчитанные «на
глаз», оставляли зазор после «Сейчас» и прятали остриё под кругом «AI-first».
Теперь линия выходит из края первого круга и остриё встаёт перед третьим.

Ещё: **фиолетовое сияние на фиолетовой стене почти не читается**, поэтому у
заголовков центр облака взят светлее — оно работает светом, а не цветом.
Оранжевому этого не нужно, стена не оранжевая.

## Собрать ролик и нарезать на части

```
sh собрать.sh "ваше видео.MOV"
sh нарезать.sh "ваше видео-готовый.mp4" 47 105 159   # четыре части
```

Числа реза — от владельца: 47 (конец блока «Стратегия»), 105 (конец
«Данных»), 159 (конец R&D, дальше профиль и дорожная карта).

**Второй раз собирать `…-готовый.mp4` нельзя**: субтитры в нём уже вжжены, и
новый заход положил бы поверх них вторую строку. Скрипт видит такое имя и
останавливается.

**Обложки готовы:** `cover.png` — на весь ролик, `cover1.jpg`…`cover4.jpg` —
по одной на часть, с подписью «Часть N» под тайтлом. Скрипт нарезки видит
пронумерованные обложки и вторую подпись поверх не рисует.

## Субтитры

**Ни одна реплика не переносится на две строки.** Каждая измерена по метрикам
шрифта и, если не влезала в полосу 940px, разрезана по словам. 142 реплики,
395 слов, самая широкая строка 883px.

**Времена из распознавания, слова из сценария.** Распознавалка ставила
водяной знак TurboScribe, рвала слова по дефису на две реплики («AI» +
«-индекс», «бизнес» + «-результатами», «AI» + «-агентов», «AI» + «-first») и
теряла ё («вовлеченность», «Четвертый», «остается»). Всё это поправлено;
короткие обрывки слиты в читаемые строки.

**Кегль вжжённых субтитров = кегль на странице.** libass (как и VSFilter)
понимает `Fontsize` не как размер em, а как высоту строки
`winAscent+winDescent` из таблицы OS/2. У Montserrat Black это 1.562em,
поэтому «Fontsize 53» рисовался в кадре как 34px — в полтора раза мельче,
чем показывает превью. Скрипт умножает кегль на 1.562, и обе дороги сборки
дают один и тот же кадр.

Слова живут в `субтитры.srt` и только там: страница-превью читает тот же
файл, который вжигает `собрать.sh`. Перерендеривать графику ради правки
слова не нужно — субтитров в слое графики нет. Если ваш ffmpeg без libass,
текст берётся из готового слоя `subs_c.mp4`/`subs_a.mp4`, и правку слов
скрипт заметит по хэшу `субтитры.sha`.

## Слой графики

`overlay_c.mp4` — цвет, `overlay_a.mp4` — маска прозрачности (в mp4 нет
альфы, `alphamerge` сшивает их обратно). Слой 176.0 c при дорожке 174.1: в
хвосте остаётся одна шапка, и `собрать.sh` держит этот кадр до конца дубля
(`tpad=stop=-1:stop_mode=clone`).

Пересобрать страницу из исходников: `python3 tools/build_index.py`.
Перерендерить слой: `python3 tools/render_overlay.py 176.0 <порт> <папка> "&subs=0"`.

## Параметры в адресе

| Параметр | Что делает |
|---|---|
| `?t=95` | открыть сразу на 95-й секунде |
| `?src=clip.mp4` | подхватить видео, лежащее рядом с файлом |
| `?guides=1` | показать границы зоны и верх картин |
| `?scrim=0` | убрать затемнение верха кадра |
| `?subs=0` | выключить субтитры |
| `?only=subs` | оставить в кадре только субтитры (рендер запасного слоя) |
| `?cover=0` | убрать заставку |
| `?rec=1` | режим записи без панели |
| `?bg=none` | прозрачный фон — под захват |
