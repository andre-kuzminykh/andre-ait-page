# Анимированная графика поверх видео — лекция 1

Слайды 1–3 лекции (`/automation/1/`), разложенные по озвучке вертикального
ролика 1080×1920: элемент появляется ровно тогда, когда о нём говорят.
Требование и тесты — `FR-SITE23` в [`SPEC-SITE.md`](../../../SPEC-SITE.md).

Открыть: <https://andre.technology/automation/1/overlay/>

## Как пользоваться

1. Открыть страницу — сразу играет анимация на демо-фоне (приближённая
   реконструкция кадра), видео не нужно.
2. **Загрузить видео** — кнопкой или перетащить mp4 в окно. Дальше часы ведёт
   само видео: перематываете ролик — графика идёт за ним.
3. **Режим записи** (или клавиша `H`) прячет панель — в кадре остаётся только
   ролик с графикой. Дальше `Во весь экран` и запись экрана.

Клавиши: `Space` — пуск/пауза, `←`/`→` — ±1 с, `Shift+←`/`→` — ±5 с, `H` — панель.

## Параметры в адресе

| Параметр | Что делает |
|---|---|
| `?t=57` | открыть сразу на 57-й секунде |
| `?src=clip.mp4` | подхватить видео, лежащее рядом с файлом |
| `?guides=1` | показать границы: зону графики, верх постеров (y638), макушку (y816) |
| `?zoneTop=48&zoneH=712` | подвинуть зону графики под конкретный кадр |
| `?scrim=0` | убрать осветление верха кадра |
| `?rec=1` | сразу режим записи (без панели) |
| `?bg=none` | прозрачный фон вместо видео — под захват в OBS/монтажке |

## Зона графики

Замеры по кадру 1080×1920: верх постеров на стене — `y638`, макушка — `y816`.
Графика живёт в `48…760` и ниже не опускается: постеры перекрывать можно
(карточки непрозрачные), голову — нет. Если в вашем дубле голова выше или
ниже, поправьте `?zoneTop=&zoneH=` и посмотрите с `?guides=1`.

## Тайминг

Времена стоят в разметке: у сцены `data-in`/`data-out`, у элемента `data-in`,
у повторного упоминания `data-hl` (подсветка уже показанного). Секунды от
начала ролика. Рядом с каждым — комментарий с фразой из озвучки, по которой
время выбрано. Сдвинулась озвучка — правятся только эти числа.

## Что взято из слайдов, а что нет

Взяты все элементы слайдов 1–3, которые звучат в озвучке. Не взяты:
бейдж «Лекция 1: Введение в разработку ИИ-стратегии» (в тексте не звучит).
Пункты «Лидеров» переставлены под порядок озвучки: ядро бизнеса (00:56) →
быстрее/дешевле (01:11) → без роста штата (01:15).

После 02:15 графики нет намеренно: финальная фраза «ИИ не отнимет у вас
работу…» в слайдах 1–3 не встречается, и кадр отдан говорящему.

## Шрифты

Montserrat лежит в `fonts/` (8 подмножеств woff2, кириллица + латиница) —
страница не зависит от Google Fonts и одинаково выглядит офлайн, из `file://`
и с сайта. Иконки Phosphor вклеены инлайновым SVG по той же причине.
